# Neural Search Engine

A semantic search system built with contrastive learning (InfoNCE) over a bi-encoder architecture.

## Project Structure

```
Neural-Search-Engine/
├── data/
│   ├── raw/              # Downloaded datasets (MS MARCO cache)
│   └── processed/        # Triplets, corpus, splits (generated by notebook)
├── notebooks/
│   ├── phase1_data_collection.ipynb   # Data download, chunking, triplet creation
│   ├── phase2_baseline.ipynb          # BM25 + TF-IDF baselines
│   ├── phase3_model.ipynb             # Bi-encoder architecture
│   ├── phase4_training.ipynb          # InfoNCE contrastive training
│   ├── phase5_vector_search.ipynb     # FAISS index + J&M book demo
│   └── phase6_evaluation.ipynb        # Recall@k, MRR comparison table
├── src/
│   ├── data_utils.py     # Chunking, loading helpers
│   ├── model.py          # BiEncoder class
│   ├── loss.py           # InfoNCE loss
│   ├── train.py          # Training loop
│   └── search.py         # search(query, k) function
├── models/               # Saved model checkpoints
├── evaluation/           # Results, tables, plots
├── demo/                 # Final demo script
└── requirements.txt
```

## Setup

```bash
pip install -r requirements.txt
```

## Dataset

**MS MARCO v2.1** (passage ranking)
- ~100,000 (query, positive passage, negative passage) triplets
- 80/10/10 train/val/test split
- Queries: real user searches from Bing
- Documents: 200–300 word web passages
